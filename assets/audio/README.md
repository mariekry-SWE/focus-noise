# Ljudfiler för Focus Noise

Lägg dina loopande ljudfiler här, t.ex.:

- `white.mp3` – white noise
- `pink.mp3` – pink noise  
- `brown.mp3` – brown noise

Filer kan vara MP3, M4A eller andra format som expo-av stöder. För sömlös loop, använd korta klipp (t.ex. 30–60 sekunder) som appen loopar.

När filerna finns: uppdatera `data/sounds.ts` och sätt `audioSource` till t.ex. `require("../../assets/audio/white.mp3")`.
